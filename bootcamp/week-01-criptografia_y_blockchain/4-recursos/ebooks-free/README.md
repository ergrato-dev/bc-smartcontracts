# 📚 Ebooks gratuitos — Semana 01

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| Bitcoin: A Peer-to-Peer Electronic Cash System | PDF (9 páginas) | El artículo original de Satoshi Nakamoto (2008) | https://bitcoin.org/bitcoin.pdf |
| Ethereum Whitepaper | Web | El documento de Vitalik Buterin (2014) que propuso los smart contracts sobre una blockchain | https://ethereum.org/es/whitepaper/ |
| Mastering Ethereum | Web / AsciiDoc (CC BY-SA) | Libro de referencia de Andreas M. Antonopoulos y Gavin Wood, libre en GitHub | https://github.com/ethereumbook/ethereumbook |
| Mastering Bitcoin | Web / AsciiDoc (CC BY-SA) | Del mismo autor; sus capítulos de claves, direcciones y firmas son la mejor explicación larga de esta semana | https://github.com/bitcoinbook/bitcoinbook |
| A Graduate Course in Applied Cryptography | PDF | Dan Boneh y Victor Shoup (Stanford); para quien quiera la matemática de hashes y firmas | https://toc.cryptobook.us/ |

- **Artículo de Bitcoin**: corto y legible; las secciones 2 a 4 son exactamente las
  Teorías 05 y 06.
- **Whitepaper de Ethereum**: en español; lee "Ethereum" y "Aplicaciones" para ver de
  dónde sale la idea de smart contract.
- **Mastering Ethereum**: capítulos 4 (*Cryptography*) y 5 (*Wallets*) esta semana; lo
  volverás a usar en todo el bootcamp.
- **Mastering Bitcoin**: capítulos 4 (*Keys and Addresses*) y 7 (*Authorization and
  Authentication*), opcional.
- **Boneh y Shoup**: avanzado y opcional; capítulos 8 (hashes) y 13 (firmas).
