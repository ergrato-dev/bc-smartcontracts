# 🌐 Webgrafía — Semana 01

| Recurso | Descripción |
| ------- | ----------- |
| [ethereum.org — Introducción a Ethereum](https://ethereum.org/es/developers/docs/intro-to-ethereum/) | Documentación oficial, en español: blockchain, Ethereum, EVM y smart contracts |
| [ethereum.org — Cuentas](https://ethereum.org/developers/docs/accounts/) | Claves, direcciones y cómo se deriva una dirección |
| [ethereum.org — Bloques](https://ethereum.org/developers/docs/blocks/) | Qué guarda un bloque real de Ethereum y cada cuánto se produce |
| [ethereum.org — Prueba de participación](https://ethereum.org/developers/docs/consensus-mechanisms/pos/) | Validadores, slots, épocas y finalidad |
| [Foundry — cast](https://getfoundry.sh/cast/overview) | Documentación oficial de `cast` |
| [Referencia de comandos de cast](https://getfoundry.sh/reference/cast/cast/) | Todos los subcomandos y sus opciones |
| [EIP-55](https://eips.ethereum.org/EIPS/eip-55) | El checksum de direcciones con mayúsculas y minúsculas |
| [EIP-191](https://eips.ethereum.org/EIPS/eip-191) | El prefijo de los mensajes firmados |
| [BIP-39](https://github.com/bitcoin/bips/blob/master/bip-0039.mediawiki) | El estándar de las frases semilla |
| [Keccak Team](https://keccak.team/keccak.html) | Página oficial de los autores de keccak |
| [Anders Brownworth — Blockchain Demo](https://andersbrownworth.com/blockchain/) | Demo interactiva: altera un bloque y mira cómo se rompe la cadena |
| [Etherscan](https://etherscan.io) | Explorador de bloques de Ethereum: busca un bloque y su *Parent Hash* |
| [Practical Cryptography for Developers](https://cryptobook.nakov.com/) | Libro web gratuito de Svetlin Nakov: hashes, firmas ECDSA y curvas elípticas con ejemplos |

- Empieza por la **documentación oficial** de ethereum.org y de Foundry: es lo que se
  mantiene al día.
- Los **EIP** y el **BIP** son las fuentes primarias: cortos, y la referencia exacta
  cuando una herramienta y un tutorial no coinciden.
- La **demo de Anders Brownworth** es la forma más rápida de interiorizar la Teoría 06.
