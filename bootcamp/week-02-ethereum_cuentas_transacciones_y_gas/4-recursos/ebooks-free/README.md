# 📚 Ebooks gratuitos — Semana 02

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| Mastering Ethereum | Web / AsciiDoc (CC BY-SA) | Libro de referencia de Andreas M. Antonopoulos y Gavin Wood, libre en GitHub | https://github.com/ethereumbook/ethereumbook |
| Mastering Ethereum (versión web) | Web | La misma obra, publicada como sitio para leer en el navegador | https://cypherpunks-core.github.io/ethereumbook/ |
| Ethereum Yellow Paper | PDF | La especificación formal de Ethereum: estado, transacciones, gas y EVM | https://ethereum.github.io/yellowpaper/paper.pdf |

- **Mastering Ethereum**: capítulos 6 (*Transactions*) y 14 (*The Ethereum Virtual
  Machine*) esta semana. La versión de GitHub es la segunda edición, que ya explica el
  EIP-1559.
- **Versión web**: cómoda para buscar un término mientras haces los ejercicios.
- **Yellow Paper**: denso y matemático, solo como consulta. Las secciones 4 (bloques,
  estado y transacciones) y 9 (el modelo de ejecución) son las de esta semana.
