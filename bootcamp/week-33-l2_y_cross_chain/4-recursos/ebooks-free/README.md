# 📚 Ebooks gratuitos — Semana 33

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| OP Stack Specification | Web | La especificación del OP Stack: depósitos, retiradas, mensajeros y predeploys | https://specs.optimism.io |
| Mastering Ethereum | Web (GitHub) | El libro de referencia de la semana 27; útil para repasar lo que una L2 equivalente a la EVM tiene que reproducir | https://github.com/ethereumbook/ethereumbook |

- **La especificación del OP Stack** es el libro de esta semana: corta por secciones, con
  diagramas, y es lo que implementa el código de OP Mainnet y Base. Lee "Deposits",
  "Withdrawals" y "Predeploys" después de las teorías 03 y 04.
- **Mastering Ethereum** no habla de L2, pero sus capítulos de la EVM explican por qué "equivalente
  a la EVM" es una promesa difícil.
