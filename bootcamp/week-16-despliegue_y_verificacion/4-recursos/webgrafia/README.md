# 🌐 Webgrafía — Semana 16

| Recurso | Descripción |
| ------- | ----------- |
| [forge script — referencia](https://getfoundry.sh/reference/forge/script) | Todas las opciones: `--broadcast`, `--account`, `--slow`, `--resume`, `--verify`. Consúltala antes de inventar un flag |
| [forge verify-contract — referencia](https://getfoundry.sh/reference/forge/verify-contract) | Verificadores, `--constructor-args`, `--guess-constructor-args`, `--watch` y `--show-standard-json-input` |
| [ethereum.org — Redes](https://ethereum.org/developers/docs/networks/) | Mainnet y testnets, para qué sirve cada una y enlaces a faucets de Sepolia |
| [ethereum.org — Web3 Secret Storage](https://ethereum.org/developers/docs/data-structures-and-encoding/web3-secret-storage/) | La especificación del keystore: `scrypt`, AES-128-CTR y el `mac` campo a campo |
| [EIP-155](https://eips.ethereum.org/EIPS/eip-155) | El chain id dentro de la firma: por qué una transacción de Sepolia no vale en mainnet |
| [Etherscan API V2](https://docs.etherscan.io/etherscan-v2) | La clave única para todas las redes de Etherscan que usa `--verify` |
| [Sourcify — documentación](https://docs.sourcify.dev/docs/intro/) | Verificación abierta y sin clave, y su API para consultar si un contrato está verificado |
| [Sepolia Etherscan](https://sepolia.etherscan.io) | El explorador donde verás tus transacciones y tu código verificado |
| [Sepolia PoW Faucet](https://sepolia-faucet.pk910.de/) | Faucet que paga ETH de Sepolia a cambio de minar en el navegador, sin cuenta |
| [Google Cloud — Sepolia faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia) | Faucet con cuenta de Google |

- Empieza por las dos referencias de Foundry: son de tu versión y salen de `--help`.
- Los faucets cambian a menudo; si ninguno funciona, pide el ETH al instructor.
