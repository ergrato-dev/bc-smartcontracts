# 📚 Ebooks gratuitos — Semana 09

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| The Foundry Book | Web / Markdown (Apache 2.0) | El manual oficial de Foundry, de la misma herramienta que usa el bootcamp. Su código fuente está en GitHub | https://github.com/foundry-rs/book |
| Building Secure Contracts | Web / Markdown (AGPL-3.0) | Guía de Trail of Bits sobre seguridad de contratos, con una parte entera sobre fuzzing y propiedades | https://github.com/crytic/building-secure-contracts |
| ethereum.org — Testing smart contracts | Web | La guía de la Ethereum Foundation sobre por qué y cómo probar contratos: tests unitarios, fuzzing, forks y verificación formal | https://ethereum.org/developers/docs/smart-contracts/testing/ |

- **The Foundry Book**: esta semana, en *Forge*, las secciones de tests, *Fuzz Testing*,
  *Fork Testing* y *Gas Tracking*; en la referencia, los cheatcodes que usas y los comandos
  `forge test`, `forge snapshot` y `forge coverage`.
- **Building Secure Contracts**: en *Program Analysis*, la introducción a fuzzing y cómo
  elegir propiedades. Las herramientas que nombra (Echidna, Medusa) llegan en la semana 24.
- **ethereum.org**: corto y sin código. Léelo para situar cada técnica de la semana en el
  conjunto: qué detecta cada una y qué se le escapa.
