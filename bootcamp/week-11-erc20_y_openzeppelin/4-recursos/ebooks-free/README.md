- **OpenZeppelin**: esta semana, *Tokens → ERC-20* (cómo crear un token y qué son los
  decimales), *Extending Contracts* (`_update`, `super` y el orden de herencia) y, en la
  referencia *API → Token → ERC20*, las páginas de `ERC20Burnable`, `ERC20Capped` y
  `SafeERC20`. Fíjate en que la URL diga `5.x`: muchas búsquedas llevan a la 4.x.
- **ethereum.org**: la página del estándar es corta; el tutorial es largo, léelo con el
  ejercicio 01 terminado.
- **Solidity by Example**: usa `pragma ^0.8.x` y no comprueba `address(0)`; compáralo con el
  tuyo.
