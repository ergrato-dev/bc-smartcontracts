# 📚 Ebooks gratuitos — Semana 04

| ------ | ------- | ----------- | ------ |
| Documentación de Solidity 0.8.38 | PDF | El manual oficial del lenguaje, de la misma versión que usa el bootcamp | https://docs.soliditylang.org/_/downloads/en/v0.8.38/pdf/ |
| Foundry Book | Web | La documentación oficial de Foundry | https://getfoundry.sh/introduction/getting-started |
| Mastering Ethereum | Web / AsciiDoc (CC BY-SA) | Libro de referencia de Andreas M. Antonopoulos y Gavin Wood, libre en GitHub | https://github.com/ethereumbook/ethereumbook |

- **Documentación de Solidity**: esta semana, *Types* (solo la parte *Value Types*),
  *Layout of State Variables in Storage* y, dentro de *Contracts*, *Visibility and
  Getters*, *Constant and Immutable State Variables* y *Functions*. Las secciones sobre
  `mapping`, arrays y `struct` son de la semana 06.
- **Foundry Book**: la referencia de `forge inspect` y `forge create`.
- **Mastering Ethereum**: del capítulo 7, *Smart Contracts and Solidity*, las secciones
  *Data Types*, *Variables: Definition and Scope*, *Functions* y *Contract Constructor*.
  *Function Modifiers*, *Error Handling*, *Events* y la herencia llegan en las semanas
  siguientes.
