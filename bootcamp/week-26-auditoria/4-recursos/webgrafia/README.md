# 🌐 Webgrafía — Semana 26

| Recurso | Descripción |
| ------- | ----------- |
| [Code4rena: categorías de severidad](https://docs.code4rena.com/awarding/judging-criteria/severity-categorization) | Cómo clasifica un concurso de auditoría cada hallazgo. Compáralo con la matriz de la teoría 03 |
| [Sherlock: criterios de evaluación](https://docs.sherlock.xyz/audits/judging/guidelines) | Las reglas de otra plataforma, con casos concretos de lo que es y no es un hallazgo |
| [Immunefi: clasificación de severidad](https://immunefi.com/immunefi-vulnerability-severity-classification-system-v2-3/) | La escala que usan los bug bounties de Immunefi |
| [Immunefi](https://immunefi.com/) | La plataforma de bug bounties más usada en Web3: programas, reglas y recompensas |
| [Informes de Code4rena](https://code4rena.com/reports) | Informes públicos de concursos, con sus hallazgos y sus PoC |
| [Publicaciones de Trail of Bits](https://github.com/trailofbits/publications) | Informes de auditoría de una firma, con la estructura de la teoría 04 |
| [OWASP Smart Contract Top 10](https://owasp.org/www-project-smart-contract-top-10/) | Las diez clases de fallo más frecuentes, según OWASP |
| [Solcurity](https://github.com/transmissions11/solcurity) | Una lista de comprobación para la revisión manual, función por función |
| [Ethernaut](https://ethernaut.openzeppelin.com/) | El CTF de OpenZeppelin: niveles con un contrato vulnerable cada uno |
| [Damn Vulnerable DeFi](https://www.damnvulnerabledefi.xyz/) | CTF de DeFi en Foundry, con el mismo formato que el ejercicio 03 |

- Las **tres escalas de severidad** no coinciden entre sí. Leerlas juntas te enseña qué se
  discute al dar una severidad: el impacto en fondos, la probabilidad y quién tiene que actuar.
- Los **informes publicados** son la mejor forma de aprender a escribir hallazgos: lee uno a la
  semana y fíjate en los títulos.
- **Damn Vulnerable DeFi** usa Foundry, así que sus niveles se juegan en el contenedor del
  bootcamp, como el ejercicio 03. Algunos usan temas de la fase 6 (AMM, préstamos): déjalos para
  después de la semana 30.
