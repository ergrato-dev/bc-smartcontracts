# 📚 Ebooks gratuitos — Semana 26

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| Smart Contract Security Field Guide | Libro web | Guía de campo para auditores: clases de vulnerabilidad, metodología y herramientas | https://scsfg.io/ |
| Ethereum Smart Contract Best Practices | Libro web | Las buenas prácticas de ConsenSys Diligence: patrones, ataques conocidos y lo que mira un auditor | https://consensysdiligence.github.io/smart-contract-best-practices/ |
| Building Secure Contracts | Libro web | La guía de Trail of Bits: cómo preparar un código para auditarlo y cómo usar sus herramientas | https://secure-contracts.com/ |

- **Smart Contract Security Field Guide** es la referencia más ordenada para la revisión manual
  de la teoría 01: cada clase de fallo con su explicación y sus defensas. Úsala como lista de
  preguntas cuando audites.
- **Ethereum Smart Contract Best Practices** lleva años siendo la lista de comprobación de muchos
  equipos. La parte de ataques conocidos repasa las semanas 21 y 22 desde el punto de vista de
  quien audita.
- **Building Secure Contracts** tiene una sección para el equipo auditado: qué documentación dar,
  cómo dejar listo el código y qué esperar del informe. Es la otra mitad de la fase 1.
