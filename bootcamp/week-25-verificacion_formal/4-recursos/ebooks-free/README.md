# 📚 Ebooks gratuitos — Semana 25

| Título | Autor | Formato | Enlace |
| ------ | ----- | ------- | ------ |
| Symbolic Fuzzing (The Fuzzing Book) | Zeller, Gopinath, Böhme, Fraser y Holler | Capítulo web | https://www.fuzzingbook.org/html/SymbolicFuzzer.html |
| Programming Z3 | Bjørner, de Moura, Nachmanson y Wintersteiger | Libro web | https://theory.stanford.edu/~nikolaj/programmingz3.html |
| SAT/SMT by Example | Dennis Yurichev | PDF | https://smt.st/ |

- **Symbolic Fuzzing** es el capítulo de ejecución simbólica de The Fuzzing Book (semana 24). Con
  código en Python, construye un ejecutor simbólico pequeño: caminos, condiciones de camino y z3
  para resolverlas. Es la teoría 01 hecha programa.
- **Programming Z3** es la guía de los autores de z3. Los primeros capítulos (lógica
  proposicional, aritmética y vectores de bits) bastan para entender qué preguntas le hace
  Halmos al solver y por qué la aritmética no lineal cuesta tanto.
- **SAT/SMT by Example** resuelve con solvers problemas concretos: puzles, criptografía,
  ingeniería inversa. Ojea el índice y elige; no hace falta leerlo entero.
