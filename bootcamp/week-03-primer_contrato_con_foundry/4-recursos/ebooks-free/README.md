# 📚 Ebooks gratuitos — Semana 03

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| Documentación de Solidity 0.8.38 | PDF | El manual oficial del lenguaje, de la misma versión que usa el bootcamp | https://docs.soliditylang.org/_/downloads/en/v0.8.38/pdf/ |
| Foundry Book | Web | La documentación oficial de Foundry: proyectos, tests, despliegue y referencia de cada comando | https://getfoundry.sh/introduction/getting-started |
| Mastering Ethereum | Web / AsciiDoc (CC BY-SA) | Libro de referencia de Andreas M. Antonopoulos y Gavin Wood, libre en GitHub | https://github.com/ethereumbook/ethereumbook |

- **Documentación de Solidity**: esta semana, *Introduction to Smart Contracts* y
  *Layout of a Solidity Source File*. Al ser la versión exacta, todo lo que leas compila
  igual en tu contenedor.
- **Foundry Book**: la referencia cuando dudes de una opción de `forge` o `cast`. Más al
  día que cualquier tutorial.
- **Mastering Ethereum**: el capítulo *Smart Contracts and Solidity* cuenta el ciclo de
  vida de un contrato. Sus ejemplos usan Solidity 0.8.26 y a veces `^`: en el bootcamp,
  siempre `0.8.38` exacto.
