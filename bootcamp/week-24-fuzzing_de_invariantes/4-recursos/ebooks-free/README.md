# 📚 Ebooks gratuitos — Semana 24

| Título | Autor | Formato | Enlace |
| ------ | ----- | ------- | ------ |
| The Fuzzing Book | Zeller, Gopinath, Böhme, Fraser y Holler | Libro web | https://www.fuzzingbook.org/ |
| Building Secure Contracts: Program analysis | Trail of Bits | Libro web | https://secure-contracts.com/program-analysis/index.html |
| Medusa | Trail of Bits | Libro web | https://secure-contracts.com/program-analysis/medusa/docs/src/index.html |

- **The Fuzzing Book** explica el fuzzing en general, con código en Python que puedes ejecutar en
  el navegador: generación aleatoria, mutación, fuzzing guiado por cobertura y reducción de la
  entrada que falla (lo que forge y Medusa llaman encoger). No habla de contratos; sirve para
  entender por qué Medusa guarda un corpus.
- **Program analysis** es la sección de la guía de seguridad de Trail of Bits sobre sus
  herramientas: Slither (semana 23), Echidna y Medusa. La parte de fuzzing enseña a elegir
  invariantes.
- **El libro de Medusa** es su documentación oficial: instalación, cada clave de `medusa.json`,
  los tipos de prueba y la lista de cheatcodes que admite. Es la referencia de la teoría 04.
