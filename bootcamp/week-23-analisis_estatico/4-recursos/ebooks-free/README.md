# 📚 Ebooks gratuitos — Semana 23

| Título | Autor | Formato | Enlace |
| ------ | ----- | ------- | ------ |
| Building Secure Contracts | Trail of Bits | Libro web | https://secure-contracts.com/ |
| Slither: A Static Analysis Framework For Smart Contracts | Feist, Grieco y Groce | Artículo (PDF) | https://arxiv.org/abs/1908.09878 |
| Static Program Analysis | Møller y Schwartzbach | Libro (PDF) | https://cs.au.dk/~amoeller/spa/ |

- **Building Secure Contracts** es la guía de seguridad de los autores de Slither. Su sección
  *Program analysis* incluye la documentación de Slither, también la de su API de Python, que
  amplía la teoría 04.
- **El artículo de Slither** explica su diseño: cómo pasa del AST de solc a SlithIR, y por qué la
  representación intermedia hace los detectores más simples y precisos.
- **Static Program Analysis** es un libro universitario sobre análisis estático en general: grafos
  de control, análisis de flujo de datos y por qué ningún análisis es a la vez completo y exacto.
  Para quien quiera ir más allá de la teoría 01; basta con los primeros capítulos.
