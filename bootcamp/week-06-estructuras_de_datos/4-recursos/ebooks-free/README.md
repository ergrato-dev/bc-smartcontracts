- **Documentación de Solidity**: esta semana, dentro de *Types*, las secciones *Reference
  Types* (*Data location*, *Arrays*, *Structs*), *Mapping Types* (incluido *Iterable
  Mappings*), *Enums* y el operador `delete`. *Layout of State Variables in Storage*
  explica dónde guarda la EVM cada mapping y cada array; se estudia a fondo en la semana 27.
- **Foundry Book**: la referencia de `cast estimate`, con la que mediste el gas de recorrer
  un array.
- **Mastering Ethereum**: del capítulo 7, *Smart Contracts and Solidity*, la sección de
  tipos de datos (*Data Types*). *Events* llega en la semana 07.
