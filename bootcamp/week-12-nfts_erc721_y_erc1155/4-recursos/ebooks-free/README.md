# 📚 Ebooks gratuitos — Semana 12

| Título | Formato | Descripción | Enlace |
| ------ | ------- | ----------- | ------ |
| Documentación de OpenZeppelin Contracts 5.x | Web (MIT) | La guía oficial de la biblioteca, con una página para ERC-721 y otra para ERC-1155, y la referencia de cada contrato | https://docs.openzeppelin.com/contracts/5.x/ |
| ethereum.org — Estándar ERC-721 | Web | La página de la Ethereum Foundation sobre ERC-721, con la interfaz completa | https://ethereum.org/developers/docs/standards/tokens/erc-721/ |
| ethereum.org — Estándar ERC-1155 | Web | El estándar multi-token: lotes, receptores y la URI con `{id}` | https://ethereum.org/developers/docs/standards/tokens/erc-1155/ |
| Solidity by Example — ERC721 | Web (gratuita) | Un ERC-721 escrito a mano en una página, con `safeTransferFrom` y el receptor | https://solidity-by-example.org/app/erc721/ |
| Solidity by Example — ERC1155 | Web (gratuita) | Un ERC-1155 escrito a mano, con las operaciones en lote | https://solidity-by-example.org/app/erc1155/ |

- **OpenZeppelin**: esta semana, *Tokens → ERC-721* y *Tokens → ERC-1155*, y en la
  referencia *API → Token → ERC721* las páginas de `ERC721`, `IERC721Receiver` y
  `ERC721Holder`. Fíjate en que la URL diga `5.x`: muchas búsquedas llevan a la 4.x, donde
  aún existían `_beforeTokenTransfer` y `Counters`.
- **ethereum.org**: dos páginas cortas; léelas después de las teorías 01 y 04.
- **Solidity by Example**: escribe a mano lo que OpenZeppelin te da hecho. Léelo con el
  ejercicio 01 terminado y busca dónde está la llamada a `onERC721Received`.
